# Atoms Lite — 视觉素材验收

> 2026-10-10。新增独立验收文档，配套 [视觉素材方案](VISUAL-ASSET-PLAN.md)。仓库原先没有单独的“视觉素材验收”文件；原 PRD T20 仍作为四头像的总验收，本文件扩展 V1–V7。所有条目均待实施/验收，不代表已生成或上线。

## 1. 先决条件：先能稳定使用，再增加视觉内容

[UI 审计](UI-AUDIT-2026-10-10.md) 中的布局、工具栏、移动端代码区、阅读位置和关键版本加载问题先关闭。素材不能掩盖面板跳动、无法操作的按钮或模糊的错误提示。

- [ ] 固定 viewport 下 Preview / Code / Versions 的面板外框坐标和尺寸一致（允许 1px 舍入误差）；切换不改变用户设定分栏。
- [ ] 桌面分栏可拖动、有上下限、支持键盘和恢复默认；移动端不强行保留两列。
- [ ] 375 / 768 / 900 / 1280px 下工具栏全部可达，必要时收进更多菜单。
- [ ] Code 文件栏可收起，小屏不固定占掉约半屏；文本区域可正常滚动。
- [ ] 标签、文件、历史版本切换不丢失应保留的阅读位置；加载、空白、失败清楚区分。
- [ ] 页面核心操作在素材 404、慢网、禁用动画时仍可用。

## 3. 通用质量门槛

### 外观与一致性

- [ ] 在真实页面中检查，而不只看孤立大图：桌面、375px、深浅色均通过。
- [ ] 与 Quiet studio 的字号、圆角、颜色、间距一致；作品是视觉主体，操作区不变成装饰画布。
- [ ] 图像透明为真实 alpha，不是棋盘图；缩小后不糊、无白边/暗边，圆形裁切不切掉角色关键轮廓。
- [ ] 重要文字由真实 DOM/代码排版提供；不依赖生图中的文字准确性。

### 交互与可访问性

- [ ] 选择卡使用原生按钮或正确的选择控件；键盘能进入、选择、退出，焦点可见。
- [ ] 装饰图 alt 为空；作品截图根据相邻文案决定简短说明，避免重复朗读；文字与图像失效独立。
- [ ] 装饰层不捕获点击、不覆盖输入和工具栏；触控目标建议至少 44px（项目易用性目标，不据此声称 WCAG 全面合规）。
- [ ] 状态除颜色外还有文字/图标；通过/失败仅对应真实行为。

### 性能、来源与上线

- [ ] 固定图片宽高/比例，图片加载不推动面板和正文；屏外懒加载。
- [ ] 首屏新增图片传输目标 ≤400KB，记录真实请求；V2 不额外下载一套主题位图。
- [ ] manifest 记录选稿、提示词/截图来源、路径、尺寸、大小、内容 hash、用途和版本绑定，不含密钥。
- [ ] 原图与生产图分开；public 仅放选定衍生图。第三方素材逐项记录来源与使用范围。
- [ ] build 通过；部署后资源 URL 200、类型/尺寸/透明正确、缓存更新可验证。
- [ ] 每批可独立回退，不影响生成、版本、发布和已有项目数据。
