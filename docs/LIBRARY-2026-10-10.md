# Useful content and starter library

References inspected: https://atoms.dev/discover (Saved/Latest), https://atoms.dev/ai-agents (role responsibilities and workflow), https://help.atoms.dev/en (search, topics, build and publish guidance). Our implementation describes only Atoms Lite features.

Added standalone Team and Help, editable prompt links, Discover search/sort/browser-only saved collection, project name/status filters. Eleven help articles cover the first build, scope, Remix, editing, error repair, retry, versions, publishing, ZIP export, storage and the shared demo account.

Added three genuinely interactive curated examples, explicitly labeled as templates: Daily Habits, The Recipe Shelf and Studio Open Day. Their source and verified behaviors are in examples/README.md. Discover now contains six examples. New covers are actual sandbox renders and tied to exact version IDs.

Verification: Discover search and bookmark persistence; Team prompt prefill without automatic generation; Help search and disclosure; app-level habit, recipe and RSVP persistence and clearing. No live model calls were required. Shared demo templates remain available to Remix; a fictional RSVP never sends an email or creates a reservation.
